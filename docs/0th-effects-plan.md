## 新しい動詞が要るもの

### A. 動きの話（既存に近い）

🔴 **第2版（2026.04）で2枚とも軽くなった。** 2024.04 版は「もう一度移動する。移動できないなら
ターンを終了する」だったが、第2版は**「１マス移動する。」**。
🔴 さらに **ダッシュの手札効果は、ユーザー判断で印字から効果を変えた**（2026-11-19）:
印字「通常の移動**または接触**に加えて、もう１回移動できる」→ アプリは
**「このターン、通常の移動をしたなら、１マス移動する。」**（接触したターンには使えず、
追加の移動は**１マスだけ**）。⇒ **この節に新しい動詞は1つも要らなくなった。**

| | 要るもの | 近い既存 |
|---|---|---|
| **ダッシュ**（赤）● | **自分が１マス移動する** | `MOVE_CHOSEN_PLAYER_ONE_CELL`（貴族の特権）が**まさに1マス移動**。相手ではなく**自分**を動かす版が要るだけ |
| **ちょっと待った！**（紫）● | 移動前のマスへ戻る → **１マス移動する** | `FORCED_MOVE_TO_PREVIOUS_CELL` ＋ 上と同じ動詞 |
| **ダッシュ**（赤）■ | **このターンに通常の移動をしたなら**、１マス移動する | 上と**同じ動詞**＋「通常の移動をしたか」の条件だけ |
| **フォース**（橙）■ | 相手を**カードの置かれた任意のマス**へ移動する | `MOVE_CHOSEN_PLAYER_ONE_CELL` は1マスだけ。距離の縛りが無い版が要る |

🔴 **「１マス移動する」は3か所が共有する**ので、**動詞を1つ作って3つとも通す**
（別々に書くと必ず食い違う＝続き698 の教訓）。
🔴🔴 **「１マス移動する」は強制移動ではない**（ユーザー確認済み・2026-11-19）。
＝**移動先は本人が選び、移動先の到達効果も起きる**。`MOVE_CHOSEN_PLAYER_ONE_CELL` は
元からその作り（本人に委任して選ばせ、裏向きなら開けてから到達させる）なので**そのまま流用できる**。
⚠ **`FORCED_MOVE` 系へ落とさないこと。** ちょっと待った！の●は
「移動前のマスに**強制移動する**」の直後に「１マス移動する」が続くので、**取り違えやすい**
（前半だけが強制移動）。
⚠ ●は**到達した本人**が動く。`MOVE_CHOSEN_PLAYER_ONE_CELL` を流用するなら、
**相手を選ばせる道へ落とさない**こと（#720 の家族。候補が自分1人でも聞きに行く作りになっている）。
⚠ ダッシュ■の「通常の移動をしたなら」は、**ムーブフェイズで実際に動いたか**を見る
（接触のターンでは使えない）。`recordMoveVisited` の類が持っている情報で足りるか、
ターンごとの印を1つ足すかは実装時に決める。
### B. 置く・動かす

| | 要るもの |
|---|---|
| **民の道の建設**（緑）■ | 相手の周囲以外の2マスの**裏向きのカードを裏向きのまま**選び、カードの無い2マスへ移す。⚠「見てはいけない」＝中身を出さない |
| **欲しがりの吊り橋**（青）■ | これを周囲以外のマスに裏向きで置き、**そのマスの周囲のカード1枚をこれの直下へ**移す |
| **仕掛けられた罠**（青）■ | これを周囲以外のマスに裏向きで置き、**そのマスの周囲のカード1枚を捨てる** |
| **誰かの落とし物**（橙）■ | これを**相手のゲート**に裏向きで置く＋1枚ドロー。`PICKUP_FROM_OPPONENT_GATE` の逆 |
| **誰かの好きな花**（桃）● | これを**相手の手札へ**渡す。このターンにオープンされていたなら1枚ドロー（`DRAW_IF_OPENED_THIS_TURN` が使える） |
| **誰かの好きな花**（桃）■ | **1番多くロックしている人の周囲**の、プレイヤーのいないマスへ**表向きで**置く＋1枚ドロー |
| **なないろのあめ**（白）● | **カードの無いすべてのマス**に山札から1枚ずつ裏向きで置く |
| **なないろのあめ**（白）■ | **縦または横1列（7マス）**に山札から1枚ずつ裏向きで置く（既にカードがあるマスにも重ねる） |

⚠ 「周囲」は前後左右と斜めの8マス。「隣」は前後左右の4マス。**この2つを取り違えない。**

### C. 見せる・宣言する

| | 要るもの |
|---|---|
| 🔴 **情報開示**（桃）● | **位置の決まった複数オープン**（場の中央1マス＋四隅4マス＝5マス）。1枚も無いなら**場のどこでも1マス**を1枚。⇒ **新しい動詞が2つ要る**（下の注） |
| **情報開示**（桃）■ | 2枚ドローして公開。**それらの手札効果はこのターン使えない**（`PUBLIC_DRAW_DISABLE_HAND_EFFECTS_CONDITIONAL_DISCARD` の条件なし版） |
| **予言者の技**（紫）■ | 2色宣言 → 1枚ドローして公開 → **宣言色ならここまでを繰り返す**。ex0「大地創造」「鑑定士の技」が同じ形（あちらは場のカードをオープン、こちらはドロー） |

🔴🔴 **情報開示の到達効果は、印字どおりに戻った**（2026-11-20・ユーザー判断「これは残したい！」）。
2026-11-19 に一度「任意の１マスのカードをオープンする。」へ縮めてこの節から消していたが、**取り消した**。
⇒ **要るものが2つ戻ってきた**:

1. **位置の決まった複数オープン。** `FLIP_UP_TO_N_WITHIN_RANGE` は「範囲の中から N 枚**選ばせる**」
   ものなので使えない。**マスの一覧を渡して、そこに在る表向きでないカードを全部オープンする**動詞が要る
   （中央 (3,3) と四隅 (0,0)(0,6)(6,0)(6,6)）。
2. 🔴 **同時に複数の到達効果が起きた時の順番。** 開けた5マスに駒が立っていたら、到達効果が
   **同時に複数**起きる。旧0thでこの札だけの話なので、**ここだけのために順番のルールを作ることになる**。
   ⇒ **この札は後回しにする**（D の節と同じ扱い）。カードは出るし、効果は自己申告で遊べる。

⚠ ぶら下がり節（「オープンするカードが１枚もないなら…」）は**5マスとも表向きだった時だけ**通る道。
   🔴 2026-11-20 のユーザー判断「これを削除」で**「あなたの隣以外」の除外が消えた**ので、そちらは
   0th拡張の「色よ、笛」と**まったく同じ**（`FLIP_UP_TO_N_WITHIN_RANGE` / `maxCount: 1` /
   `withinCells` を渡さない＝場の49マス）＝**新しく作るものは無い**。

### D. いちばん重いもの（最後に回す）

| | なぜ重いか |
|---|---|
| **強欲なパレット**（黒）■ | **いつでも使える**（`usableAnytime`）。色を1色宣言し、**相手全員が「宣言色を1枚渡す」か「3枚捨てる」を自分で選ぶ**。相手ごとの選択＝委任が人数分走る |
| **にじいろの呪い**（黒）● | 空いているロックエリアに**これを表向きで置く**だけ。リメイクの「誘惑の黒の烙印」（`black-contract-brand`）の到達と**同じ一文**なので、そちらが使っている仕掛けをそのまま使える |
| 🔴 **にじいろの呪い**（黒）★ | **新しいルールそのもの**。これの置かれたロックエリアへのロックに**同色2枚以上を要求する**。ロックの判定（`maybeAnnounceLock` / `getLockedCount`）に手を入れることになる。⚠ 「置く」は「ロック」ではない＝7色勝利には数えない。烙印が近いが**同じではない**（あちらは手札2枚を捨ててロックする） |
| **にじいろの呪い**（黒）■ | 1番多くロックしている人を選び、**その人が上記の到達効果を得る**（委任）。⚠ ★はカードに付いてくる決まりなので、**選ばれた相手のロックエリアでもそのまま効く** |
| **いろ落ちガエル**（黒）● | 全員が手札を全部捨てる＋**これを1番少なくロックしている人の手札へ渡す**（自分の手札に加えない） |
| **いろ落ちガエル**（黒）■ | 1番多くロックしている**全員**が自分のロックを1枚選んで捨てる＋自分の手札を全部捨てる |
| **反撃**（赤）■ | **接触の宣言に割り込む**（リメイクの「カウンターロック」と同じ入口）＋**自分からその相手に接触し返す**。⚠ 補足に「反撃の接触に対しても反撃できる」とあるので**入れ子になり得る** |

⚠ **反撃**の●（手札が1番少ないなら2枚ドローして1枚捨てる）は `DRAW_IF_LOWEST_WEALTH` と
`DISCARD_ONE_HAND_CARD` の組み合わせで足りる見込み。条件の見方だけ確かめること。

## 進め方（おすすめ）

1. 「既にある動詞で足りる」分を先に入れて、`npm test` に1枚1件ずつ足す。
2. A の「もう一度移動する」を**1つの動詞**で作って3枚を通す。
3. B・C を足す。
4. D は1枚ずつ。**にじいろの呪いは最後**（ロックの判定に触るので、他が全部そろってからの方が安全）。
   🔴 **情報開示●も後回し**（2026-11-20 に印字へ戻ったため）。**同時に複数の到達が起きる順番**を
   決めることになるので、D と同じ重さだと思った方がよい。

⚠ 進み具合は `node tools/check-cards.mjs` が毎回出す
（`ⓘ 旧0th 19 種 … 効果データ N/19・テスト N/19`）。
⚠ 動詞を足したら **`tools/check-effect-helpers.mjs`** が「手札側と到達側の両方に口が在るか」を
見る（#477・続き746 の家族）。片方に足し忘れると**黙って何も起きない**。
⚠ 効果の入口で「選ぶ権利を持つ席」を立てるのを忘れると、**相手の効果の案内がこちらに出る**
（#706・続き746）。`tools/check-effect-seat.mjs` が見張っている。
