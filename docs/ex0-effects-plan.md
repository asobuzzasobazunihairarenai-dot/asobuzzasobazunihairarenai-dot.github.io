# 0th拡張の効果を自動処理にするための作業表

0th拡張（0th EDITION 拡張）の33種を、**1枚ずつ自動処理にしていく**ための調べ書き。
カードの絵・データ・文・テストモードまでは入っている（続き649）。ここは**効果だけ**の話。

## 大前提

🔴 **効果データが在るカードだけが自動処理される。** `CARD_EFFECTS` に載っていないカードは
今までどおり**文を読んでプレイヤーが自分で処理する**（ユドンリウムコネクト方式＝このプロジェクトの
元々の段階目標）。だから**半端なデータを置くのは、何も置かないより悪い**——間違った処理が勝手に走る。
**1枚を最後まで仕上げてから載せる。**

ⓘ `canAutoProcessArrival` は `.arrival` か `.arrivalOptions` が在るかだけを見る。
`hasHandEffectData` は `handEffect` か `handEffectOptions` が在るかだけを見る。
つまり**「到達だけ自動／手札効果は手で」も作りとして成立する**（データが無い側は、
そのカードがまだ未実装だった時と**まったく同じ**＝文を読んで自分で処理する）。
重い仕組みが要る側を待たせて軽い側を止める意味は無いので、**片側だけでも入れる**方針にした。
その場合は**カードデータのコメントに「もう片方はまだ」と必ず書く**。

**選択式（「以下の効果のうち１つ得る」）のカードは、善処の原則の判定が2か所ある**:
`isArrivalOptionUsable`（到達）と `isHandEffectOptionUsable`（手札）。
🔴 **片方だけに書くと「押せるのに何も起きない」選択肢ができる。** さらに
`explainHandEffectOptionUnusable` にも理由の文を足さないと「押せないのに理由が出ない」になる。

## 調べて分かったルールの土台（実装の前にここを押さえる）

アプリ内ヘルプの用語集（`src/help-content.ja.js`。総合ルールの条文から書き起こしたもの）より:

- **「場」＝盤面中央の7×7の計49マスだけ。** ロックエリア・捨て場・手札は含まない。
  ⇒ 「場の表向きのカード」を探す時に**ロックエリアを混ぜてはいけない**。
- **「到達」＝表向きのカードの上に駒が置かれたタイミング。**
  ⇒ **駒のいないマスのカードをオープンしても到達は起きない。**
  ⇒ 逆に**駒がいるマスのカードをオープンしたら到達する**（サフランの実装がそうなっており、
  ユーザー報告「自分の足元をオープンしても到達効果が発動しない」を受けて直した前例がある）。
- 🔴 **「何もないマス」と「カードの置かれていないマス」は別。**
  前者は**カードも駒も無い**、後者は**カードが無いだけ（駒はいてよい）**。
  大地創造は前者、迷いの森は後者。**カードの文が書き分けているので、取り違えない。**
- **「隣」＝前後左右の4マス。「周囲」＝斜めも含む8マス。** 別の概念。
- **「１番上の原則」**: マスのカードを1枚だけ対象にする効果は、常にそのマスの一番上。
  state では**トークン配列の末尾が一番上**。
- **「善処の原則」**: できない選択肢は**選べない**（＝光らせない）。全部できないなら不発で、
  不発でもそのカードは手札に加わる。

## 決まっていること（実装時に忘れない）

- **ファーストカード・エターナルカードはリメイクのものを使う**（ユーザー確認済み）。0th拡張には無い。
- **なないろの欠片はリメイクのものと同じ**（文も絵も）。0th拡張としては作っていない。
- **紅の鉄拳の S** は使う人が決める。**手札にある赤のカードの枚数まで**。
  **Sは1以上**なので、赤が手札に1枚も無いならこの手札効果は**使えない**（＝そもそも光らせない）。
- **ONLYカードは1枚ずつ**しか山札に入らない（データに入れてある）。

## テストの書き方で気をつけること

- 🔴 **テスト用の `pickLocation` は、候補に無いマスを指定してもそのまま返す**
  （`resolveLocation` のフォールバック）。だから「候補の絞り込みが効いているか」は
  **座標を指定する形では検査できない**。**対象が1つも無い状態を作って「何も起きない」ことで
  裏から検査する**（色寄せの笛の色の絞り込みがこの形）。
- 🔴 **「オープンしない」は、テストの中では誰もオープンしないので素通りする。**
  印（`arrivalSuppressed`）そのものを見る（`{ kind: "tokenFlag" }`）。
- **検査を足したら、わざと壊して落ちるか試す**（続き619）。色寄せの笛では
  「色の絞り込みを外す／表向きの判定を外す／範囲を狭める」の3通りで落ちることを確認した。
